# Donation O, Goddess

별도 빌드 없이 배포하는 HTML/CSS/JavaScript 사이트입니다. 로컬 검증 시 이 폴더를 HTTP 서버의 루트로 열고 Chrome에서 접속합니다. 영상과 포트폴리오 이동에는 인터넷 연결이 필요합니다.

## v13 변경

- 핵심 플레이의 제목·설명 묶음과 스크린샷의 세로 중심을 맞췄습니다. 기본 조작의 번호·제목은 왼쪽 정렬하며 상단 여백을 조정했습니다. 키와 마우스 강조 영역은 원본 테두리 안쪽에 정렬했습니다.
- 캐릭터 3종을 15388×8476 PNG 원본에서 다시 추출했습니다. 본문은 2560×2048 무손실 WebP, 확대 보기는 긴 변 2560px 이미지를 사용합니다. 이전 표시용 이미지를 단순 확대하지 않았습니다.
- 제공받은 PPT 예시와 키보드·마우스 그림을 기본 조작 안내에 반영했습니다. 조작 버튼을 클릭하면 해당 키나 마우스 영역이 금빛으로 반복해서 반짝입니다. 이동, 공격, 카메라 회전, 확대·축소, 카메라 고정, 스킬, 대시, 점프, 상호작용, 인벤토리, 신 페이지를 선택할 수 있습니다.
- 카메라 고정은 Y로 표기하고 Y키 강조에 연결했습니다. 조작 선택은 사이트 안내용이며 실제 키 입력이나 브라우저 휠을 가로채지 않습니다. 동작 줄이기 설정에서는 점멸 대신 고정 강조를 표시합니다.
- 마지막 제목을 화면 중앙에 배치하고 설문 안내, 후원 다시 받기, 제작지원 및 글꼴 출처는 화면 하단에 배치했습니다.
- Chrome 데스크톱과 390×844 모바일에서 버튼 선택과 키 강조, 마지막 화면 배치를 확인했습니다. 데스크톱에서 기본 조작과 팀 소개 사이의 앞뒤 휠 전환도 확인했습니다. 조작 매핑·휠·전환 복구·갤러리 검사와 JavaScript 구문 검사를 통과했습니다.
- 수정 전 파일은 Donation-O-Goddess_versions/v12_before_controls에 보관합니다. C:/Project는 원본 이미지 읽기에만 사용했고 SVN 명령이나 쓰기 작업은 하지 않았습니다.

## v12 변경

- 첫 입장 화면을 화면 전체에 맞추고, 압축된 키아트 대신 제공받은 2399×1349 PNG 원본을 사용합니다. 모바일에서도 배경은 화면을 채우며 로고는 별도로 배치합니다.
- 전체 색상을 금빛·모래색·갈색으로 변경했습니다. 버튼에는 hover, focus, press 반응을 적용하고 마우스 움직임에 따라 금빛 먼지가 흩어집니다. 먼지는 최대 100개로 제한하며 입력이 멈추면 사라집니다. 동작 줄이기 설정과 터치 환경에서는 먼지를 표시하지 않습니다.
- 영상 위의 휠 입력이 iframe 내부로 들어가 전환을 건너뛰는 문제를 수정했습니다. 영상은 미리보기 버튼을 누르면 대화상자에서 재생하며, 닫을 때 재생 프레임을 비웁니다.
- 화면이 섹션 중간에 걸려 있어도 현재 화면에서 다음 경계로 전환합니다. 전환 완료 직후의 불필요한 입력 잠금도 제거했습니다. 긴 섹션 내부와 모바일의 기본 스크롤은 유지합니다.
- 캐릭터와 바로 가기 순서를 네페르 → 헤루 → 인푸로 통일했습니다. 헤루는 데스크톱에서 확대해 원본 이미지의 하단 끝이 화면 아래에 위치하도록 조정하고, 모바일에서는 하단을 자연스럽게 흐리게 처리합니다.
- 마지막 안내에 제작지원 표기와 제공받은 KOCCA 한국콘텐츠진흥원 로고를 추가했습니다.
- 상단의 후원 다시 받기 중앙 / 더 보기 오른쪽 배치를 유지합니다. 파일 버전 쿼리를 갱신해 이전 CSS와 JavaScript 캐시의 영향을 줄였습니다.
- Chrome 기본 화면과 390×844 모바일 화면에서 배치, 앞뒤 휠 전환, 사진 넘김, 영상 열기·닫기, 캐릭터 선택을 확인했습니다. JavaScript 구문 검사와 휠 경계·전환 복구·갤러리·마스크 비율 검사를 통과했습니다.
- 수정 전 로컬 파일은 Donation-O-Goddess_versions/v11_before_desert에 보관했습니다. C:/Project와 SVN에는 쓰기 작업을 하지 않았습니다.

## v11 변경

- 데스크톱의 페이지 경계에서 휠을 입력하면 잉크 전환으로 다음 또는 이전 장면을 표시합니다. 메뉴와 오른쪽 목차도 같은 전환을 사용합니다. 긴 장면 내부, 모바일, 브라우저 확대 입력은 기본 스크롤 동작을 유지합니다.
- 전환 마스크 SVG에 preserveAspectRatio="none"을 적용했습니다. 높이가 긴 마스크 영역에서 SVG가 비율을 유지하며 축소되어 위쪽에 직선 모양의 투명한 띠를 만들던 문제를 수정했습니다.
- 전환 중에는 화면 크기의 영역만 고정해서 캡처하고, 완료 후 실제 스크롤을 목적 장면에 맞춥니다. 완료·실패·시간 초과 경로에서 고정 영역과 입력 잠금을 해제합니다.
- 제목만 먼저 보이는 화면과 내용의 순차 등장은 사용하지 않습니다. 동작 줄이기 설정에서는 전환을 생략합니다.
- 제공받은 네페르 초상화를 브라우저 탭 아이콘과 모바일 홈 화면 아이콘에 적용했습니다.

## 유지한 구성

- 홈 → 게임 소개 → 영상 → 핵심 플레이 → 캐릭터 → 기본 조작 → 팀 소개 → 마지막 안내.
- 핵심 플레이는 전투와 퍼즐 / 신들의 도네이션 / 협동 속의 경쟁입니다. 앞의 두 항목에는 사진이 두 장씩 있으며 SVG 화살표·방향키·드래그로 넘길 수 있습니다.
- 스크린샷은 원래 비율을 유지하고 본문 이미지는 확대할 수 있습니다. 첫 화면 대표 이미지에는 확대 기능을 두지 않습니다.
- 캐릭터 설명과 얼굴 중심 인푸 초상화, 파라오의 분노 팀원 10명의 포트폴리오 링크를 유지했습니다.
- 제목은 KMU80 성곡 Serif, 본문은 ONE 모바일고딕 OTF Regular입니다. 단어 단위 줄바꿈과 한 줄 소개 문장을 유지합니다.
- REC는 실제 녹화가 아닌 시각 연출입니다. 처음 입장할 때 후원 확인 버튼의 금화 효과를 표시합니다.

## 검증

- Chrome에서 http://127.0.0.1:8000/에 접속해 전환 문제를 재현한 뒤, 수정 후 휠의 앞뒤 이동과 전환 경계, 완료 후 입력 복구를 확인했습니다.
- 사진 넘김으로 01 / 02와 02 / 02가 바뀌고 전투·퍼즐 및 후원·채팅 사진이 표시되는지 확인했습니다. 실제 좌표 클릭 시 장면의 스크롤 위치도 유지됩니다.
- JavaScript 구문 검사, 휠 경계·긴 장면·확대 입력 검사, 전환 종료·오류 처리 검사, 갤러리 실행 검사를 통과했습니다.
- 1280×720, 1920×1080, 2560×1305, 900×1100 비율로 SVG를 실제 마스크 영역에 렌더링해 전환 시작 시 위아래에 투명한 띠가 없는지 검사했습니다. 검사 파일과 화면 증거는 배포 폴더 밖 tmp에 보관합니다.
- 이전 로컬 버전은 Donation-O-Goddess_versions/v10에 보관했습니다. C:/Project와 SVN은 변경하지 않았습니다.
